## Timing model

Plan for a 09:00-17:30 classroom day. Keep a visible timer, announce evidence checkpoints before each lab, and use the TTT segments to teach facilitation technique rather than adding more product lecture.

| Time | Duration | Segment | Trainer actions |
| --- | ---: | --- | --- |
| 09:00 | 10 min | Welcome | Confirm objectives, room roles, and cost-path choice. |
| 09:10 | 10 min | Module B framing | Explain the seven controls and evidence templates. |
| 09:20 | 35 min | Lab 0 setup | Verify `uv`, GitHub token, Copilot custom agents, skills, and MCP servers. |
| 09:55 | 15 min | TTT segment 1 | Show how to coach blocked setup without taking keyboard control. |
| 10:10 | 30 min | Lab 1 assess | Learners complete portfolio/customer assessment evidence. |
| 10:40 | 15 min | Break | Triage environment blockers. |
| 10:55 | 35 min | Lab 2 design RAI | Facilitate design, RAI Standard V2, and Customer Impact Assessment. |
| 11:30 | 10 min | TTT segment 2 | Demonstrate prompt critique and evidence review. |
| 11:40 | 45 min | Lab 3 WAR | Run Azure Well-Architected Review across all pillars. |
| 12:25 | 45 min | Lunch | Optional office hours. |
| 13:10 | 45 min | Lab 4 PoC | Run ingest, chat, agents, and custom MCP server. |
| 13:55 | 10 min | TTT segment 3 | Teach how to connect PoC findings to adoption risk. |
| 14:05 | 45 min | Lab 5 deploy | Compare free path plan with Azure Bicep deployment. |
| 14:50 | 5 min | Evidence checkpoint | Confirm B.1.1 through B.3.1 artifacts exist. |
| 14:55 | 15 min | Break | Reset services and credentials. |
| 15:10 | 45 min | Lab 6 validate | Run functional tests, RAI checks, and LLM-as-judge evaluation. |
| 15:55 | 40 min | Lab 7 operate | Produce SOPs, sign-off, post-deploy WAR Operational Excellence actions. |
| 16:35 | 35 min | Lab X migration | Swap `INFERENCE_PROVIDER` to Azure AI Foundry and re-run. |
| 17:10 | 15 min | Grading calibration | Use the rubric and compare evidence samples. |
| 17:25 | 5 min | Close | Capture feedback and next steps. |

## Facilitation checkpoints

- At 10:40, every learner should have a running app or a paired support plan.
- At 14:50, every team should have draft evidence for B.1.1, B.2.1, B.2.2, B.2.3, and B.3.1.
- At 17:10, every team should be able to explain the configuration-only migration path.

## Trainer staffing

Use one lead instructor and one coach for every 12-15 learners. Assign one coach to environment issues and one to evidence quality when class size exceeds 20.
