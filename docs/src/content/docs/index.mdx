This training website equips instructors to deliver a one-day, classroom-led MicroHack using the **Contoso AI Assistant** reference application: an agentic RAG FastAPI app with modular inference and a configuration-only path from GitHub Models to Azure AI Foundry.

## Who this is for

- Trainers preparing a Train-the-Trainer (TTT) delivery.
- Coaches validating pupil evidence for the AI Platform on Microsoft Azure Specialization.
- Technical leads who need a repeatable Module B readiness, design, deployment, validation, and operations workshop.

## Prerequisites

- Node 24 and npm for the website.
- Python 3.12 managed with `uv` for the reference app.
- GitHub account with Copilot access, GitHub Models access, and a GitHub PAT stored as `GITHUB_TOKEN`.
- Optional Azure subscription with permissions for Azure AI Foundry, Azure OpenAI, Azure AI Search, Application Insights, Key Vault, and resource group deployment.
- PowerShell 7 for the Bicep deployment scripts.

## Cost paths

### GitHub Models zero-cost classroom path

Use `INFERENCE_PROVIDER=github_models` as the default path. Learners set `GITHUB_TOKEN`, build a local index, run chat/evaluation locally, and demonstrate agent and MCP integrations without provisioning Azure AI resources.

### Azure path

Use `INFERENCE_PROVIDER=azure_openai` or `INFERENCE_PROVIDER=azure_ai_foundry` for production-oriented labs. Lab X proves the migration by changing configuration only:

```powershell
$env:INFERENCE_PROVIDER = "azure_ai_foundry"
$env:AZURE_AI_FOUNDRY_PROJECT_ENDPOINT = "https://<project-endpoint>"
aiplatform chat "How does Contoso govern AI operations?"
```

No application code changes are allowed for the provider swap.
