## Concept

GitHub Copilot custom agents and skills let trainers shape assistant behavior for repeatable workshop tasks. In this repo, custom agents live under `.github/agents/*.agent.md` and skills live under `.github/skills/`.

## Classroom use

Use them to:

- Review evidence templates consistently.
- Generate scenario-specific facilitation prompts.
- Coach learners through setup and validation issues.
- Demonstrate how AI-assisted delivery can be governed with repo-scoped instructions.

## Good trainer pattern

Ask Copilot to produce a draft, then require the learner to validate facts, add business context, and attach command output. Copilot output alone is not sufficient evidence.
